# 无模型晨报试用

默认工作日北京时间08:00启动，生成后发送HTML正文和HTML附件。GitHub排队与数据抓取会影响到达时间。保留原HTML设计、自选股、Tavily检索和QQ邮件配置，模型密钥与原AI代码不删除。无模型任务不注入模型密钥，也不调用模型API。

## 恢复与试用

- 定时任务：Actions Variables的BRIEF_MODE缺省或no-model时使用无模型；改为ai恢复原分析流程，需确保模型可调用。
- 手动运行“每日股票分析”：brief_mode选no-model或ai。原mode选项仅影响AI流程，无模型固定生成完整四部分。
- 修改.github/no-model-trial标记会发送一次试用。常规脚本提交不会自动发送。
- 禁用Actions中的“每日股票分析”可暂停；Revert本次工作流修改可回滚。
- 无模型按周一到周五运行，不另行识别交易所节假日；行情显示实际数据日期。

## 内容与限制

新闻窗口72小时，机构观点90天，均要求可解析的发布日期；无法核实日期的结果排除。只允许官方披露、权威财经媒体和投行自身网站，排除股吧、论坛、评论。统一URL和近似标题去重，同URL在新闻和股票部分交叉引用合并，但不承诺事件级语义去重。

中文正文提供短连续原文摘录，不调用模型归纳。英文只提供原文链接和未翻译提示。标题关键词匹配利好/利空，混合及未匹配事项按中性，不预测涨跌，不能判断是否超预期、回购提议和实际完成等复杂语义。

列出最多10条新闻，计划17项国际市场指标，以及关注公司关联新闻和公告线索。任何缺失均明示，不为补足条数而编造。末尾覆盖统计便于比较无模型限制。国际市场用Yahoo已完成日线参考、保守时段过滤；不是交易所官方结算价，汇率用最近完整UTC日线。收益率变化用基点；超过7天数据视作缺失。关注公司部分不展示行情总表；内部采集数据不代表已核实的公司新闻。

## 配置与费用

复用STOCK_LIST、TAVILY_API_KEYS、EMAIL_SENDER、EMAIL_RECEIVERS、EMAIL_PASSWORD。可选BRIEF_MODE=no-model、SMTP_HOST=smtp.qq.com、SMTP_PORT=465。变量设在Actions Variables，密钥设Secrets。无模型不消费模型额度，但13只股票每轮约20次Tavily基础搜索，重跑仍会消耗搜索额度。

## 验证与隐私

node --test scripts/no_model_brief.test.mjs覆盖来源白名单、发布时间、近似去重、否定/混合事件、未完成日线和HTML转义。Python发送脚本做语法编译。公开日志只记录数量与SMTP状态，不显示密钥、股票明细或原始报告；个性化报告不上传公开artifact。SMTP接受不等于收件方已打开。

本页仅针对个人Fork试用，未同步上游英文全量指南；原项目其他API、Web、本地流程保持原实现。


## ChatGPT检索与分析测试

新增独立的 `chatgpt-brief-delivery.yml`，接收 ChatGPT 阅读公开原文后生成的中文新闻摘要及分析。协议与验证步骤见 [chatgpt-brief-bridge.md](chatgpt-brief-bridge.md)。无需新增模型API密钥；原有AI及无模型路径保留。此阶段不替换原08:00发送任务。新闻及机构观点由ChatGPT整理；关注公司补充公告线索仍由脚本采集，不能把整个报告称为逐条人工核验。公开仓库不保存个人自选股组合或收件地址。


## 关注公司关联信息（当前展示）

删除自选股行情总表，不展示收盘价、期间涨跌幅、成交量额、换手率或均线占位卡片。私有关注公司配置与内部行情采集接口保持兼容，个性化报告不发布到公开仓库。

只保留重要新闻标题或事实摘要明确提及公司名称、完整代码的关联内容，并交叉引用原新闻序号与链接。事实摘要、分析边界与未经逐条核验的补充公告检索线索分别标注；同一来源不重复列为线索。不依据同行业、题材相近推断关联；没有关联新闻或公告线索的公司不逐一生成空白卡片。无模型路径不将标题摘录包装成语义分析。

新闻前保留新增风险与公告进展、A股市场广度与成交活跃度、未来5—10个交易日事件日历。ChatGPT桥接可传riskUpdates、marketBreadth、eventCalendar三个可选文章数组；来源及字段校验与新闻一致，无核实资料则显示覆盖缺口。市场数据注明统计范围。事件区分新披露、持续关注、已公告安排、预约可变更和待核实；附来源日期与核实时间。未列出不能理解为近期没有事件，计划窗口开始不等于已经实施。

验证：`node --test scripts/no_model_brief.test.mjs scripts/chatgpt_brief.test.mjs`。Brief renderer checks仅执行离线检查，不读取私有环境、不生成或发送实际简报。修改共享渲染同时作用于ChatGPT桥接和无模型路径；未更改模型、密钥、关注公司配置或发送计划。仅查看样稿不得更新会触发邮件的.github/chatgpt-brief.json。此Fork专用说明无对应英文版。
