# 无模型晨报试用

默认工作日北京时间08:00启动，生成后发送HTML正文和HTML附件。GitHub排队与数据抓取会影响到达时间。保留原HTML设计、自选股、Tavily检索和QQ邮件配置，模型密钥与原AI代码不删除。无模型任务不注入模型密钥，也不调用模型API。

## 恢复与试用

- 定时任务：Actions Variables的BRIEF_MODE缺省或no-model时使用无模型；改为ai恢复原分析流程，需确保模型可调用。
- 手动运行“每日股票分析”：brief_mode选no-model或ai。原mode选项仅影响AI流程，无模型固定生成完整四部分。
- 修改.github/no-model-trial标记会发送一次试用。常规脚本提交不会自动发送。
- 禁用Actions中的“每日股票分析”可暂停；Revert本次工作流修改可回滚。
- 无模型按周一到周五运行，不另行识别交易所节假日；行情显示实际数据日期。

## 内容与限制

新闻窗口72小时，机构观点90天，均要求可解析的发布日期；无法核实日期的结果排除。只允许官方披露、权威财经媒体和投行自身网站，排除股吧、论坛、评论。统一URL和近似标题去重，同URL在新闻和股票部分交叉引用合并，但不承诺事件级语义去重。

中文正文提供短连续原文摘录，不调用模型归纳。英文只提供原文链接和未翻译提示。标题关键词匹配利好/利空，混合及未匹配事项按中性，不预测涨跌，不能判断是否超预期、回购提议和实际完成等复杂语义。

列出最多10条新闻，计划17项国际市场指标，以及自选股行情和公告。任何缺失均明示，不为补足条数而编造。末尾覆盖统计便于比较无模型限制。国际市场用Yahoo已完成日线参考、保守时段过滤；不是交易所官方结算价，汇率用最近完整UTC日线。收益率变化用基点；超过7天数据视作缺失。腾讯财经行情显示日期，20/60日区间用前复权日线。

## 配置与费用

复用STOCK_LIST、TAVILY_API_KEYS、EMAIL_SENDER、EMAIL_RECEIVERS、EMAIL_PASSWORD。可选BRIEF_MODE=no-model、SMTP_HOST=smtp.qq.com、SMTP_PORT=465。变量设在Actions Variables，密钥设Secrets。无模型不消费模型额度，但13只股票每轮约20次Tavily基础搜索，重跑仍会消耗搜索额度。

## 验证与隐私

node --test scripts/no_model_brief.test.mjs覆盖来源白名单、发布时间、近似去重、否定/混合事件、未完成日线和HTML转义。Python发送脚本做语法编译。公开日志只记录数量与SMTP状态，不显示密钥、股票明细或原始报告；个性化报告不上传公开artifact。SMTP接受不等于收件方已打开。

本页仅针对个人Fork试用，未同步上游英文全量指南；原项目其他API、Web、本地流程保持原实现。


## ChatGPT检索与分析测试

新增独立的 `chatgpt-brief-delivery.yml`，接收 ChatGPT 阅读公开原文后生成的中文新闻摘要及分析。协议与验证步骤见 [chatgpt-brief-bridge.md](chatgpt-brief-bridge.md)。无需新增模型API密钥；原有AI及无模型路径保留。此阶段不替换原08:00发送任务。新闻及机构观点由ChatGPT整理；行情和自选股公告线索仍由脚本采集，不能把整个报告称为逐条人工核验。公开仓库不保存个人自选股组合或收件地址。


## 自选股表格与公司关联信息

行情集中展示为一张表：股票代码、股票名称、收盘参考（元）、日涨跌（%）、成交额（亿元）、成交量（万股）、换手率（%）、近20日区间（元）、近60日区间（元）。名称下方显示对应交易日，代码链接行情来源；手机可横向查看。缺失值显示待核实。20/60日继续使用前复权日线最低价至最高价，尚未更换为期间涨跌幅或均线。

关联新闻放在表格下方：只有重要新闻标题或已整理事实摘要明确提及公司名称或完整代码时才关联，并交叉引用原新闻序号与来源。已整理事实、分析边界与未经逐条核验的补充公告检索线索分别标示；同一来源不重复作为公告线索。不依据同行业、题材相近推断公司关联。无模型路径没有语义摘要时如实提示，不将标题摘录包装成模型分析。

“后续关注事件未全面核实”表示尚未逐家公司核验财报预约披露、股东大会及回购或减持期限等官方未来事项，不能理解为近期没有事件；预约日期可能变更。当前版本未建立完整事件日历。

离线渲染检查：`node --test scripts/no_model_brief.test.mjs scripts/chatgpt_brief.test.mjs`。Brief renderer checks工作流仅执行离线测试，不读取私有环境、不生成实际简报或发送邮件。上述变化同时作用于ChatGPT桥接和无模型HTML渲染；未改模型、密钥、自选股配置或发送计划。此Fork专用说明无对应英文版。


## 期间涨跌幅、均线与三项优先内容（2026-10-17）

主表最后两列改为近20日涨跌幅（%）、近60日涨跌幅（%）。采用本期前复权收盘价与20/60根有效交易日线前收盘价比较，分别至少需要21/61个收盘价。MA20、MA60使用最近20/60个有效收盘价的算术平均，收盘相对均线的偏离率放在个股分析区。历史日线必须与该行收盘参考同日；不能确认前复权、样本不够或日期不一致时明确留缺，不用区间、周涨幅或不复权价格代替。

在新闻前增加新增风险与公告进展、A股市场广度与成交活跃度、未来5—10个交易日事件日历。ChatGPT桥接可传riskUpdates、marketBreadth、eventCalendar三个可选文章数组，字段及来源校验与新闻一致；没有核实资料时显示覆盖缺口。无模型路径不会凭标题自动生成这三类语义结论。广度与成交额标清沪深或含北交所等范围，20日成交均额没有连续数据则留缺。事件应区分新披露、持续关注、已公告安排、预约可变更和待核实，附原文日期与核实时间。事件重复时交叉引用；旧公告不得伪称当天新增。

这些内容不改变邮件计划或模型设置。仅查看样稿时不得更新会触发邮件的.github/chatgpt-brief.json。离线检查同时覆盖历史样本数量、均线与涨跌幅不同分母、日期重复、补充来源及字段校验。
