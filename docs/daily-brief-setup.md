## 必需配置

在仓库 Settings → Secrets and variables → Actions 中填写：

| 位置 | 名称 | 内容 |
| --- | --- | --- |
| Variables | STOCK_LIST | 最新关注股票代码，用英文逗号分隔；不含账号或密钥 |
| Secrets | 一个受支持的模型密钥，例如 DEEPSEEK_API_KEY | 相应服务商的 API Key；不要填 QQ 邮箱授权码 |
| Secrets | 一个新闻检索密钥，例如 TAVILY_API_KEYS | 相应搜索服务 API Key |
| Variables | EMAIL_SENDER | 发件人邮箱 |
| Variables | EMAIL_RECEIVERS | 收件人邮箱，多个用英文逗号分隔 |
| Secrets | EMAIL_PASSWORD | QQ 邮箱 SMTP 授权码 |

直接使用 DEEPSEEK_API_KEY 时项目自带适配。其他兼容服务需要同时配置 OPENAI_API_KEY、OPENAI_BASE_URL、OPENAI_MODEL，具体见 full-guide.md。ChatGPT 订阅不会自动把可供 Actions 使用的 API Key 写入仓库。

密钥仅存 Secrets，不提交到代码、Issue 或公开日志。检查工作流只输出“是否已配置”等状态，不回显密钥或自选股内容。

## 目标报告口径（仍需完成接入与运行验证）

原项目默认输出决策仪表盘，尚不等于以下定制格式；不能以邮件通道测试成功代替完整简报验收。

1. 中文 HTML 正文优先，手机直接阅读；HTML 附件用于归档。
2. 十条去重重要新闻，包含有来源的公司公告和财报要点。
3. 至少十项已完成的隔夜国际市场及宏观数据，逐项写清数值、变化、单位、数据时点、来源链接；缺失时说明，不补造。
4. 可核实的投行与具名分析师观点：机构、作者、发布日期、原文链接；旧观点明确标注日期。
5. 最新自选股行情、成交额、换手率、20/60交易日区间及公告；缺失数据不强行作趋势结论。
6. 只处理交易所、上市公司、政府及央行官方披露、权威财经新闻；排除股吧、匿名爆料及网友评论。
7. 公司事项按利好／利空／中性标注，附公告编号或媒体名称、客观事实摘要及原文链接。利好／利空描述事项性质，不构成股价预测。
8. 不输出主观臆测、涨跌预测、买卖点或操作建议；相关新闻与自选股无明确联系时不强行关联。
9. 固定风险提示：本内容仅信息整理，不构成投资建议，请查阅交易所原始公告核实。

日期口径：晨报在发送日 08:00 前收集信息；A 股行情使用最近已完成交易日，海外市场使用其最近已完成交易时段。新闻观察窗与数据发布日期单独标明。
